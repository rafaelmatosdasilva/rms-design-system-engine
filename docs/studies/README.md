# Studies

What the skill changes, measured. Each study asks the same requests twice, once with Claude alone and once with the skill. The results are scored by code, never by eye, and every run is kept so anyone can check it.

## The studies

| Study | What it measures |
|---|---|
| [With and without the skill](with-and-without-the-skill.md) | Building components and screens from Figma, prototyping with the design system, and the skill's own efficiency, on three models |

## The data behind them

- **Every measurement.** [The results log](../../test/skill-evals/RESULTS.md) has one entry per run of the skill evaluation, each with what changed and what it scored.
- **What the runs taught.** [The findings](../../test/skill-evals/FINDINGS.md) keep each case a run taught: the evidence, the guesses it ruled out and what changed because of it. Studies are written from these, never from memory.
- **Every run, kept.** [The records](../../test/skill-evals/records/) hold each run as it happened, so any number above can be traced back to its runs.

## Adding a study

- **One page per study**, in this folder, named for its question.
- **The same shape as the first one.** It opens with the question and the answer, then says how it was measured, the results, what it means for a team, what it costs, its limits and how to reproduce it.
- **A row in the table above**, so it is found here.
