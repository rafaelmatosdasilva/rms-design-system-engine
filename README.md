Design system knowledge is scattered across tools and workflows that rarely talk to each other. RMS Design System Engine connects Figma, your code and your documentation, checks them against your own rules and brings everything together into one shared knowledge layer. It shows teams their system’s health, what needs attention and exactly what to do next, helping humans and AI agents maintain the system with confidence.

# Get started

You need [Claude Code](https://claude.com/claude-code), [Node.js](https://nodejs.org) 22+ and [Git](https://git-scm.com). [Google Chrome](https://google.com/chrome) and TypeScript 5 are recommended; the installer tells you if they are missing.

1. Ask Claude Code to install the engine:

   ```bash
   curl -fsSL https://raw.githubusercontent.com/rafaelmatosdasilva/rms-design-system-engine/main/install.sh | bash
   ```

2. Restart Claude Code.
3. Set up your project:

   ```text
   /rms-design-system-engine set up this project
   ```

Then ask in plain words, such as `/rms-design-system-engine check the button`. [See every command](https://github.com/rafaelmatosdasilva/rms-design-system-engine/blob/main/docs/features.md).

# Who it's for

- **Design-led teams** working in Figma who want to review their library, document their design system and verify accessibility.
- **Design and engineering teams** who need to maintain parity between Figma and code, verify implementations against design intent and catch inconsistencies as designs and code evolve.
- **Code-first teams** who want to improve the reliability, accessibility and maintainability of their codebase, document components, track design system health and ensure AI-generated code follows their implementation rules.

---

# Security and enterprise

- **Runs on your machines.** No server, no account and no telemetry. It talks only to the services you already use, listed host by host for your firewall.
- **Your data stays yours.** Tokens stay in each person's own `.env`, and code people wrote is never changed: findings come back as patches.
- **Nothing extra to trust.** No npm dependencies. Every release is signed and comes with a software bill of materials.
- **Compliance answered.** GDPR, SOC 2, ISO 27001, HIPAA and the AI model's terms, each in one line.

[For IT and security teams](https://github.com/rafaelmatosdasilva/rms-design-system-engine/blob/main/.github/SECURITY.md#for-it-and-security-teams) · [Security and data](https://github.com/rafaelmatosdasilva/rms-design-system-engine/blob/main/docs/security.md#security-and-data) · [Assurance case](https://github.com/rafaelmatosdasilva/rms-design-system-engine/blob/main/docs/security.md#assurance-case) · [Report a vulnerability](https://github.com/rafaelmatosdasilva/rms-design-system-engine/blob/main/.github/SECURITY.md#report-a-vulnerability)
